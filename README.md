# 中东地区地图

一个交互式的中东地区地图可视化项目，展示国家边界、国际关系、石油输出路线、军事基地等战略信息。

## 在线预览

直接用浏览器打开 `index.html` 即可运行。

## 功能特性

### 地图显示
- 国家边界（按宗教派系着色：逊尼派、什叶派、犹太教）
- 国家名称标签
- 点击国家查看详细信息面板

### 国际关系（🔗）
- 绿色线条：盟友关系
- 红色线条：敌对关系
- 支持非国家实体（真主党、哈马斯、胡塞武装等）

### 石油输出（🛢️）
- 金色虚线：石油输出路线
- 从中东产油国指向买家
- 买家包括：英国、法国、德国、意大利、希腊、荷兰、西班牙、中国、日本、韩国、印度、美国等

### 资源标注（⛽）
- 油田/气田位置
- 河流（水资源）
- 战略港口（霍尔木兹海峡、苏伊士运河、曼德海峡等）

### 军事基地（⚔️）
- 美军基地（蓝色）
- 俄军基地（红色）
- 战略要地（紫色）

### 国家详情面板
- 政权信息、政体、领袖
- 民族、宗教、政治势力分布图
- 盟友/敌对关系
- 石油输出目的地

## 文件结构

```

├── index.html          # 主页面
├── styles.css          # 样式文件

├── main.js            # 地图初始化、核心函数

├── me-countries.geojson  # 精确边界数据（可选）
└── README.md
```

## 使用方法

1. 打开 `index.html`
2. 点击顶部按钮切换显示：
   - 🗺️ 国家边界
   - 🔤 国名标签
   - 🔗 国际关系
   - ⛽ 资源标注
   - ⚔️ 军事基地
   - 🛢️ 石油输出
3. 点击任意国家查看详细信息

## 技术栈

- **地图库**: Leaflet.js
- **图表库**: ECharts
- **地图瓦片**: CARTO OpenStreetMap

## 自定义

### 添加新国家
1. 在 `data.js` 的 `countryData` 中添加国家信息
2. 在 `details.js` 中添加详细数据
3. 在 `geojson.js` 的 `countryCenters` 中添加坐标
4. 如需边界，在 `me-countries.geojson` 中添加

### 修改连线样式
- 盟友线：绿色 (`#22c55e`)，在 `ui.js` 的 `drawRelationshipLines` 中修改
- 敌对线：红色 (`#ef4444`)
- 石油线：金色虚线 (`#FFD700`)
