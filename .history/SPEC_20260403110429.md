## Project Overview

- **Project Name**: Middle East Regional Map
- **Type**: Interactive Leaflet Map
- **Core Functionality**: Display Middle East countries with regional boundaries, country flags/names, and detailed tooltips on hover
- **Target Users**: Educational, research, or general reference purposes

## Visual & Rendering Specification

### Map Setup

- **Library**: Leaflet.js with OpenStreetMap tiles
- **Center**: Middle East region (approximately lat: 29, lon: 47)
- **Zoom Level**: Initial zoom 5, min zoom 4, max zoom 8
- **Map Type**: CartoDB Positron (light, clean basemap)

### Country Styling

- Each country has a distinct fill color
- Regions within the same country share the same fill color
- Stroke: white, 1px weight for separation
- Fill opacity: 0.6

### Country Labels

- Country name displayed in center of each country block
- Font: Bold, 14-16px
- Country flag displayed next to name (emoji flags)
- Background: semi-transparent white panel

### Tooltip Content (on hover)

- Region name (province/state)
- Regime name
- Regime type (e.g., Republic, Monarchy, etc.)
- Current leader
- Official ideology
- Primary ethnicity
- Main religion
- Population (formatted with commas)
- Main economic source

## Interaction Specification

### Mouse Hover

- Highlight current region with increased opacity (0.8)
- Show tooltip with all required information
- Cursor changes to pointer

### Mouse Out

- Restore original opacity (0.6)
- Hide tooltip

## Technical Requirements

- Single HTML file with embedded CSS and JavaScript
- Leaflet.js loaded from CDN
- GeoJSON data embedded in JavaScript
- No external dependencies beyond Leaflet CDN

## Acceptance Criteria

1. Map loads and displays Middle East region correctly
2. All countries visible with distinct fill colors
3. Country names and flags displayed on each country block
4. Hovering over any region shows tooltip with all 9 data points
5. Tooltip displays correct information for each specific region
6. Map is pannable and zoomable
